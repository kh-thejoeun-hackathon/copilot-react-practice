# Copilot React Practice

GitHub Copilot을 처음 사용하는 교육을 위한 React 시작 프로젝트입니다. 복잡한 설정을 직접 만들지 않고, 준비된 화면에서 바로 기능 구현을 연습할 수 있습니다.

## 내 저장소로 복사하기

1. 이 페이지 위쪽의 **Use this template**를 선택합니다.
2. **Create a new repository**를 선택합니다.
3. 저장소 이름을 정하고 **Create repository**를 선택합니다.
4. 새로 만들어진 내 저장소의 주소를 복사합니다.

## Visual Studio Code에서 열기

1. Visual Studio Code를 실행합니다.
2. 위쪽 메뉴에서 **View → Command Palette**를 선택합니다.
3. `Git: Clone`을 입력하고 선택합니다.
4. 복사한 내 저장소 주소를 붙여 넣습니다.
5. 저장할 위치를 고른 뒤 **Open**을 선택합니다.

## 실행하기

Copilot 채팅에서 **Agent**를 선택한 뒤 아래 요청을 보냅니다.

```text
현재 열려 있는 연습 프로젝트를 실행하고 싶습니다.
필요한 작업을 먼저 설명하고, 제가 확인하면 실행해 주세요.
```

Agent가 설명한 내용을 확인한 뒤 실행을 승인합니다. 브라우저에 `React 연습 프로젝트가 준비되었습니다.`가 나타나면 준비가 끝난 것입니다.

## 문제가 생겼을 때

오류 메시지를 Copilot 채팅에 그대로 붙여 넣고 다음과 같이 요청합니다.

```text
아래 오류가 발생했습니다.
원인을 쉬운 말로 설명하고, 해결 순서를 제안해 주세요.
제가 확인하기 전에는 파일을 변경하지 마세요.

[오류 메시지 붙여 넣기]
```
